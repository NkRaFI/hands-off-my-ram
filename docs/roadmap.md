# Roadmap

The roadmap contains ten implementation phases followed by four controlled improvement phases. Each phase is started only by an explicit user request.

| Phase | Outcome | Blender required? |
|---:|---|:---:|
| 1 | Project foundation plus one-batch intake and validation of the already-approved asset manifest | No |
| 2 | Player movement, camera, boundaries, and collisions | No |
| 3 | Kenney polygon city foundation, landmarks, and navigable chase routes | No |
| 4 | Ram Sam opening portal, theft, and basic running | No |
| 5 | Bat attack, hit detection, vulnerability, RAM drops | No |
| 6 | NPC state machines, targeting, theft, reactions, endless loop | No |
| 7 | Rocket Elon assistance meter and support portal | No |
| 8 | Progression, balancing, accessibility, mobile controls | No |
| 9 | Voices, dialogue, music, sound effects, subtitles | No |
| 10 | Finished MVP city and lighting, local saves, complete QA, static deployment readiness | No |
| 11 | Optional environment additions beyond the finished MVP city | Possibly; pause if needed |
| 12 | Final faces, clothing refinements, and original character branding | Yes; prerequisite gate |
| 13 | Final animations, expressions, and lip movement | Yes; prerequisite gate |
| 14 | Performance optimization, compatibility, and release QA | Possibly |

## Global phase workflow

1. Read the phase task.
2. Confirm included and excluded work.
3. Implement the smallest complete increment.
4. Run automated checks.
5. Complete the manual browser checklist.
6. Fix failures.
7. Update durable documentation where required.
8. Commit the verified result.
9. Stop and wait for the user to start the next phase.

Asset discovery is preproduction work and is already complete. Phase 1 performed the original download/intake. The user-approved 2026-11-04 Ultimate Modular Men amendment supersedes the character role assignment; all later phases consume its recorded stable IDs and may not silently select replacements.

## MVP checkpoint

At the end of Phase 10, the game is complete and deployable with a finished, vibrant Kenney polygon city and cohesive clothed open characters. The five landmarks must be visually distinct and readable, the streets and public spaces must feel complete at gameplay camera distance, and lighting must support the target mood. This is a finished game city using approved assets, not a pixel-for-pixel recreation of the concept image. Final character faces, clothing refinements, original character emblems, and animation cleanup remain optional later improvements. Phase 11 may add optional environmental extras, but is not required to finish the city or ship the MVP.
