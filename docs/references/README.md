# Visual references

## `target-gameplay-look.png`

Canonical concept for environment vibrancy, low-poly character proportions, third-person chase composition, glowing RAM, portal effects, city density, and HUD tone.

It is a concept image rather than a literal screenshot. Production assets must be optimized and must replace any third-party-like marks with project-owned branding.

## `ramai-emblem-concept.png`

Concept for the fictional RamAI emblem: six RAM-module forms arranged as an interlocking spiral around a processor core.

The detailed raster is not the final small-scale mark. A later polishing phase should create simplified flat, monochrome, and 3D-safe variants.
